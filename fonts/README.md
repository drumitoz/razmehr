# Local fonts

These are the site's existing font families, served locally as WOFF2 with
`font-display: swap`. No page needs to contact Google Fonts.

Original font data and licenses: https://github.com/google/fonts

- `ofl/vazirmatn/Vazirmatn[wght].ttf` — weights 100–900, Persian/Arabic/Latin.
- `ofl/marcellus/Marcellus-Regular.ttf` — weight 400.
- `ofl/cormorant/Cormorant[wght].ttf` — weights 300–700.
- `ofl/cormorant/Cormorant-Italic[wght].ttf` — italic, weights 300–700.

Only container compression was changed (TTF to WOFF2 with fontTools); no
outlines or character coverage were edited. The corresponding SIL Open Font
License notices are included in this directory.
