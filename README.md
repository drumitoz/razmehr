# رازمهر — سایت عمارت زیبایی رازمهر

سایت تک‌صفحه‌ای سالن و آکادمی زیبایی رازمهر (یزد).

## ساختار
- `index.html` — کل سایت
- `img/` — عکس‌ها
- `CNAME` — دامنه اختصاصی (razmehrbeauty.com)

## عوض کردن عکس‌ها
هر عکس را با همین اسم در پوشه `img/` جایگزین کنید:
logo.png, mo.jpg, menubg.jpg, ostad.jpg, bagh.jpg,
vidrang.jpg, vidkeratin.jpg, vidmikap.jpg, vidtatoo.jpg,
