# رازمهر — سایت عمارت زیبایی رازمهر

سایت تک‌صفحه‌ای سالن و آکادمی زیبایی رازمهر (یزد) — razmehrbeauty.com

## ساختار
- `index.html` — کل سایت
- `shop.html` — صفحه مستقل همه محصولات (آماده اتصال به `shop.razmehrbeauty.com`)
- `products.js` — منبع واحد اطلاعات محصولات برای صفحه اصلی و فروشگاه
- `img/` — همه عکس‌ها
- `CNAME` — دامنه اختصاصی

## راهنمای عکس‌ها
هر عکس را با **دقیقاً همین اسم** در پوشه `img/` بگذارید تا سر جایش بنشیند.

> قانون ثابت تصاویر محصول: خود عکس اصلی، نوشته‌ها، لوگو و بسته‌بندی هیچ‌وقت بازطراحی یا دست‌کاری نمی‌شوند. جلوه استودیویی فقط با قاب و پس‌زمینه CSS اطراف تصویر ساخته می‌شود. برای افزودن محصول جدید فقط یک‌بار اطلاعات آن را در `products.js` اضافه کنید؛ صفحه اصلی و فروشگاه مستقل هر دو خودکار به‌روز می‌شوند.

### گالری نمونه‌کار هر خدمت (هرکدام تا ۱۰ عکس)
هر خدمت یک کد دارد. عکس‌ها را با شماره ۱ تا ۱۰ بگذارید،
مثلاً: `rang1.jpg`, `rang2.jpg` … `rang10.jpg`
**لازم نیست همه ۱۰ تا را بگذارید** — جاهای خالی خودکار نامرئی می‌شوند.

| خدمت | کد عکس |
|---|---|
| عروس | `arus1` … `arus10` |
| رنگ و لایت | `rang1` … `rang10` |
| احیا و کراتین و اسکالپ | `keratin1` … `keratin10` |
| کوتاهی | `kutahi1` … `kutahi10` |
| میکاپ | `mikap1` … `mikap10` |
| شینیون | `shinion1` … `shinion10` |
| بافت مو | `baft1` … `baft10` |
| ناخن | `nakhon1` … `nakhon10` |
| پدیکور و کف‌سابی | `pedikur1` … `pedikur10` |
| مژه | `mozhe1` … `mozhe10` |
| آرایش دائم | `daem1` … `daem10` |
| تتو بدن | `tatoo1` … `tatoo10` |
| اصلاح صورت و ابرو | `eslah1` … `eslah10` |

> همه عکس‌ها با حروف کوچک و پسوند `.jpg` ذخیره شوند. عکس‌های عمودی و افقی در گالری به‌صورت مربعی نمایش داده می‌شوند و با کلیک، نسخه کامل آن‌ها باز می‌شود.
